# Smart Component AI

An easy ECE + AI educational web prototype for identifying common electronic components from an uploaded image.

## Features
- Image upload and preview
- Drag-and-drop support
- AI-style component identification result
- Component category, function, common use and symbol
- Responsive design for mobile and desktop

## Components
Resistor, Capacitor, LED, Diode and Transistor.

## Run
Open `index.html` in a browser.

## Important
This version is a front-end educational prototype. The result is simulated in JavaScript. A real AI classifier can later be connected using a trained TensorFlow/Teachable Machine model or an AI inference API.
